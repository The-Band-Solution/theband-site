# theband-site — ARQUIVADO

**Este repositório não serve o site.** O site do The Band vive em
[`The-Band-Solution/theband`, branch `gh-pages`](https://github.com/The-Band-Solution/theband/tree/gh-pages),
com o CNAME apontando para <https://theband.dev>.

## Por que foi arquivado

Em 2026-09-01 encontramos aqui a copy do template Astroplate ainda dentro —
*"Ready to build your next project with Astro?"*, com botão para
`zeon-studio/astroplate`. O repositório nunca esteve no ar, e era uma **segunda
fonte da verdade sem dono**: alguém editaria aqui achando que é o site, e a
mudança nunca apareceria.

Arquivar restaura a fonte única e preserva o histórico.

## Se um dia o site voltar a ser um projeto Astro

O conteúdo aqui continua acessível. A decisão de migrar o site da `gh-pages`
para um gerador estático é legítima — o que não pode existir é **os dois ao
mesmo tempo**, que era o estado até hoje.
